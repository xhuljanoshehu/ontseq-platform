# Sniffles2 candidate adapter

## Scope and status

The adapter executes Sniffles2 v2.8.0 for one intake-approved aligned BAM and normalizes a
deliberately narrow VCF subset. It is a reproducible research interface, not an AML-validated
caller policy. Every event is `unclassified`, `reportable: false` and requires expert review.

## Execution contract

The executable receives a shell-free argument vector equivalent to:

```text
sniffles --input INPUT.bam --vcf OUTPUT.vcf --threads N \
  --minsupport POLICY --minsvlen POLICY --mapq POLICY \
  --pass-only --symbolic --no-progress
```

`--mosaic` is added only when the loaded policy explicitly selects mosaic mode. The adapter never
sets `--output-rnames` or `--allow-overwrite`. Existing VCF output is a hard stop.

The official interface locks are the Sniffles2
[CLI configuration source](https://github.com/fritzsedlazeck/Sniffles/blob/master/src/sniffles/config.py),
[VCF implementation](https://github.com/fritzsedlazeck/Sniffles/blob/master/src/sniffles/vcf.py)
and [Bioconda recipe](https://bioconda.github.io/recipes/sniffles/README.html).

## Normalization map

| VCF evidence | Normalized field |
| --- | --- |
| `SVTYPE=DEL/DUP/INV/INS` | deletion, duplication, inversion or insertion event |
| `SVTYPE=BND/TRA` plus ALT mate or `CHR2/END` | translocation candidate with two one-base loci |
| `POS`, `END`, `SVLEN` | 0-based, half-open primary locus |
| absolute `SVLEN` | explicit event length; required for insertions |
| `SUPPORT` | supporting reads; mandatory and rechecked against policy |
| `QUAL`, `FILTER` | quality and filter evidence |
| `VAF`, or FORMAT `DV/(DR+DV)` | variant allele fraction |
| `COVERAGE` | full numeric coverage context plus its arithmetic mean |
| `STRAND`, `NM` | orientation and mean alignment edit-distance evidence |
| `PRECISE/IMPRECISE`, `STDEV_POS`, `STDEV_LEN` | breakpoint precision evidence |

The source record ID, REF/ALT sequence, read names, VCF sample label and source path are not copied.
Event IDs are deterministic counters generated by the adapter.

## Rejection and no-call semantics

Each record is either normalized or assigned exactly one counted rejection reason. Reasons include
non-PASS filters, unsupported/disallowed types, missing or low support, configured quality failure,
imprecise calls when prohibited, invalid coordinates, missing breakend mates and non-canonical
contigs. Malformed VCF document headers fail the artifact rather than silently returning zero.

If no record survives, the module status is `NO_CALL`. This means only that no Sniffles2 record
passed the loaded technical policy. It is never rendered as a biological or clinical negative.

## Interpretation boundary

- A BND is not a gene fusion. Fusion assertion requires build-aware gene annotation, target
  observability, partner coverage and fusion-specific validation.
- A coordinate is not an ISCN statement. Cytoband normalization, clonality and authorized ISCN
  conformance remain separate review gates.
- Caller PASS is not platform validity. Promotion requires predefined benchmark thresholds by
  assay, coverage, tumor/blast fraction, event class and genomic context.
- The current policy has no minimum QUAL because inventing an unvalidated cutoff would create a
  false safety claim. This must be resolved through the locked benchmark.

## Test coverage

Unit tests cover accepted DEL and BND records, VAF fallback, policy rejection, canonical-contig
gating, privacy exclusions, `NO_CALL` wording and command construction. CI additionally generates
a synthetic positive long-read BAM and executes real samtools, Cramino and Sniffles2 binaries.
Neither BAM nor VCF is uploaded as a CI artifact.
